## C29 : la faute directe dans le total de lancers (STAT-1, D85 et D86)
`scenarios/C29.mjs` (tablette, 8 vérifications). Un match de contrôle à trois équipes est joué avec de vrais appuis (9 événements : 5 lancers, 4 fautes dont une sans joueur et une d'équipe) ; toutes les valeurs attendues sont écrites en dur, calculées à la main (voir l'en-tête du fichier : OFF % Bleu 1/2, Gris 1/3, Noir 1/4, contre 1/2, 1/2, 1/1 sur les lancers seuls).
1. vue d'ensemble : compteurs, tableau rendu, définition de l'OFF à jour ; DÉF %, F % et scores inchangés ;
2. cumul d'équipe et classement : mêmes pourcentages ; détail par adversaire et `situations[adversaire]` sur les lancers seuls ; arrêtée / continue d'ensemble avec les fautes ;
3. head-to-head : grille du match inchangée, arrêtée / continue des duels inchangés ;
4. zones OFF : la faute compte dans la case de sa position ; une faute sans position compte dans le total, dans aucune case ; zones DÉF inchangées ;
5. par période : fautes dans la période où elles ont lieu (une période qui n'a que des fautes est listée) ;
6. joueurs : faute attribuée = lancer raté (aussi par situation) ; faute « ? » et faute d'équipe : aucune ligne ;
7. exports (XLSX et CSV) : colonnes anciennes aux valeurs d'avant (en dur), colonnes neuves en fin de ligne, moyenne de la colonne Actions = OFF % de l'écran ; si `kinball.C29.avant.html` (copie de `main`) est dans `KINBALL_AVANT`, comparaison complète des colonnes anciennes avec cette copie ;
8. match sans aucune faute : tous les compteurs et colonnes neufs égaux aux anciens.
Adaptations d'anciennes suites : C15·3 (le recalcul indépendant compte les fautes), C18 (cumul des cases OFF avec les fautes localisées), C28·1 et C28·8 (une cinquième colonne en fin de la feuille Actions), C13B·12, C19, C20, C21, C23 (la colonne neuve s'ajoute à celles qu'on retire des comparaisons avec la version d'avant).
Contrôle négatif : `KINBALL_HTML=<dossier avec une copie de main et les liens vers vendor/, kbsite.js…>/index.html KINBALL_ONLY=C29 node tests/run.mjs` fait échouer les 8 vérifications.
