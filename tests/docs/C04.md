# C04 : fiche joueur cumulée (D105)

Suite `tests/scenarios/C04.mjs`, tablette et téléphone. Un match joué par l'interface avec effectifs (possession suivie, Bleu_p1 lance et fait une faute), puis deux copies rangées dans `MATCHES_DB` comme deux matchs de l'équipe `T_C04`.

1. Cumul d'équipe, onglet Joueurs : les lignes sont cliquables ; toucher Bleu_p1 ouvre l'écran `playerCard` ; titre et nom en texte (nom `<b>Jo</b> & Cie`, aucun balisage) ; deux lignes de match, la plus récente d'abord ; lancers, fautes, OFF % et +/- égaux à la somme des deux matchs calculée sur `S` ; pas de débordement horizontal ; une ligne de match ouvre les stats archivées, ↶ du retour (`navBack`) rouvre la fiche et quitte l'archive, un second retour revient à l'équipe.
2. Joueur sans match : message vide ; tri par colonne (premier appui décroissant, second croissant) ; `S` et `MATCHES_DB` inchangés ; `currentPlayerCard` hors de `S`.

Contrôle négatif : `KINBALL_HTML=<copie de main avant C04> KINBALL_ONLY=C04` : les quatre vérifications échouent.
