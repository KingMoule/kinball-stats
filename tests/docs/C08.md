## C08 : export « tous les matchs » (format long, D84, D89)
`scenarios/C08.mjs` (tablette et téléphone, 7 vérifications). Les matchs de test sont des copies du match joué, posées dans `MATCHES_DB` / `DELETED_MATCHES` : A (terminé, homonymes « Laval »), B (en cours, noms hostiles `=1+1`, `a"b;c\nd`, `-Lévis`), C (0 action), D (supprimé), E (ancien : sans `at`, sans date, sans `activeTeams`), plus un vrai duel à deux équipes. Le bouton de l'écran Sauvegarde est cliqué et le téléchargement relu par un lecteur CSV du test.
1. exactement les actions de A, B, E ; ordre date puis saisie ; un seul en-tête ; nom de fichier horodaté ;
2. colonnes d'identité et de contenu (ID, date, heure, période, type, résultat, situation, phase, joueur, code de faute, zones, coordonnées, scores et joueurs par emplacement, équipes en valeurs) ; ancien match : date et heure vides ;
3. aucun en-tête avec un nom d'équipe ; noms hostiles protégés ; duel : emplacement 3 vide ;
4. CSV actions, brut, JSON, XLSX et structures d'un match identiques avant et après l'export ; si `kinball.C08.avant.html` (copie de `main`) est dans `KINBALL_AVANT`, en-têtes identiques à ceux de `main` ;
5. BOM, `\r\n`, `;`, virgules décimales, entiers sans virgule ; 6. lecture seule (stockage, corbeille, `S` même objet, `localStorage`), un match illisible n'empêche rien ; 7. colonnes constantes avec joueurs hostiles.
Contrôle négatif : `KINBALL_HTML=<index.html de main> KINBALL_ONLY=C08` : les 7 vérifications échouent (le bouton n'existe pas).
