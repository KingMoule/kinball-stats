## C08 : export « tous les matchs » (format long, D84, D89)
`scenarios/C08.mjs` (tablette et téléphone, 12 vérifications). Les matchs de test sont des copies du match joué, posées dans `MATCHES_DB` / `DELETED_MATCHES` : A (terminé, homonymes « Laval »), B (en cours, noms hostiles `=1+1`, `a"b;c\nd`, `-Lévis`), C (0 action), D (supprimé), E (ancien : sans `at`, sans date, sans `activeTeams`), plus un vrai duel à deux équipes. Le bouton de l'écran Sauvegarde est cliqué et le téléchargement relu par un lecteur CSV du test.
1. exactement les actions de A, B, E ; ordre date puis saisie ; un seul en-tête ; nom de fichier horodaté ;
2. colonnes d'identité et de contenu (ID, date, heure, période, type, résultat, situation, phase, joueur, code de faute, zones, coordonnées, scores et joueurs par emplacement, équipes en valeurs) ; ancien match : date et heure vides ;
3. aucun en-tête avec un nom d'équipe ; noms hostiles protégés ; duel : emplacement 3 vide ;
4. CSV actions, brut, JSON, XLSX et structures d'un match identiques avant et après l'export ; si `kinball.C08.avant.html` (copie de `main`) est dans `KINBALL_AVANT`, en-têtes identiques à ceux de `main` ;
5. BOM, `\r\n`, `;`, virgules décimales, entiers sans virgule ; 6. lecture seule (stockage, corbeille, `S` même objet, `localStorage`), un match illisible n'empêche rien ; 7. colonnes constantes avec joueurs hostiles.
8-12 (audit : le match en cours se lit dans `S`) : 8 `writeMatchDoc` en erreur ; 9 écriture jamais revenue ; 10 match absent de `MATCHES_DB` (pas de message « Aucun match… ») ; 11 copie en retard sur `S` : toutes les lignes de `S`, une fois, numéros 1..n ; 12 archive consultée : `S` ignoré, match de `S` en corbeille exclu. `installer(app)` remplace `S` par un état neuf (sauf `garderS`) pour que le match joué ne compte pas comme « en cours » dans 1 à 7.
Contrôle négatif : `KINBALL_HTML=<index.html de main> KINBALL_ONLY=C08` : les 7 premières échouent (le bouton n'existe pas) ; sur le commit 52eb1c56 (avant le correctif), 8, 9, 10, 11 échouent (et 4, dont le `S` conservé change la liste).
